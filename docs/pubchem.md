| **SPARQL endpoint** | [https://qlever.dev/api/pubchem](https://qlever.dev/api/pubchem) |

<a name="tp1">PubChem</a> is the *world's largest collection of freely accessible chemical information*
[<a href="#citeref1">1</a>,<a href="#citeref2">2</a>].

## Entities

The main classes are:

* Metabolite: ligand, e.g. <a name="tp2">drug</a> / drug-like compound
* Assay: measures some property of, for example, the protein-ligand binding

## Data model

The data model is described in the 2015 paper [<a href="#citeref2">2</a>].
